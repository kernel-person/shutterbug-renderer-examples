## See what you can build

Four standalone Java examples demonstrate the free public API. Each runs with the separately installed ShutterBug Renderer provider; no extra SDK plugin is needed on the server.

### Painter's Easel

Capture a scene, paint it with cyan, magenta and yellow brush strokes, then collect the finished map. Includes a wood-and-metal easel, a textured linen canvas with an opaque backing, and a matching brush.

**[VIDEO PLACEHOLDER — in-game easel placement, continuous painting and collecting the finished map]**

### Redstone Camera

Place and aim a camera, pulse redstone, see a brief flash when capture starts, then collect the generated photo from its inventory. The stored angle includes up/down aiming.

**[VIDEO PLACEHOLDER — in-game camera trigger, lens flash, inventory photo pickup and resulting image]**

### Admin POV Monitor

An authorized admin can view periodic rendered snapshots from a selected online player's viewpoint on a private handheld map or desk monitor. This is not screen sharing: it excludes HUD, chat, inventory, client shaders and audio. Updates are best-effort, not guaranteed one-second video; delayed images are marked stale. No frame recording history is stored.

**[VIDEO PLACEHOLDER — solo self-view demonstration, clearly labelled; handheld receiver, desk monitor and stopping the feed]**

### Postcards

Use `/postcard` to turn your current view into a persistent map: a minimal starting point for your own integration.

[Developer wiki and API reference](https://kernel-person.github.io/shutterbug-renderer-api/) · [Example source and installation instructions](https://github.com/kernel-person/shutterbug-renderer-examples)

Free and paid add-ons are welcome. Tell your buyers that ShutterBug Renderer is required and purchased separately. The server needs a valid Renderer license; each player does not need a separate purchase.

Supported Renderer platforms: macOS ARM64 and Linux x86-64. Windows is coming soon. The examples/resource pack target Minecraft 26.2 with Paper 26.2 and Java 25.
