5. From the clean exact commit, generate the four-JAR plugin ZIP and a Git source ZIP, verify all manifest/file hashes and matching source identities, and hand both to the publication coordinator.
6. Keep commercial runtime acceptance and all public push/release/upload actions pending. Preserve older artifacts and user marketplace copy.
